# Токены

Токены определены в `:root` файла [`assets/design-system.css`](../../assets/design-system.css). Семантические роли ссылаются на примитивы, чтобы общие значения не дублировались.

## Цвет

| Токен | Значение | Использование |
| --- | --- | --- |
| `--palette-white` | `#FFFFFF` | Белый примитив. |
| `--palette-gray-50` | `#F4F4F4` | Поверхность карточек. |
| `--palette-gray-100` | `#E8E8E8` | Фон меток. |
| `--palette-gray-400` | `#8B8B8B` | Исходный muted сайта; оставлен для совместимости. Не использовать для мелкого текста новых экранов. |
| `--palette-gray-700` | `#696969` | Вторичный текст новых экранов. |
| `--palette-gray-900` | `#19191A` | Основной текст. |
| `--palette-blue-500` | `#0079FF` | Фирменный акцент и контур фокуса. |
| `--palette-blue-700` | `#0068D7` | Интерактивный текст с контрастом около 5.3:1 на белом. |
| `--palette-blue-500-08` | `rgba(0, 121, 255, 0.08)` | Тихая hover-подложка. |

Семантические роли: `--color-page-bg`, `--color-text`, `--color-muted`, `--color-text-secondary`, `--color-tag-bg`, `--color-card-bg`, `--color-hover`, `--color-link`, `--color-hover-bg`.

`--color-muted` и `--color-hover` сохраняют исходные цвета сайта. Их контраст недостаточен для мелкого текста на белом фоне; для новых экранов используйте `--color-text-secondary` или `--color-link`.

## Типографика

Основной шрифт — Golos Text, веса 400, 500 и 600. Стек задан токеном `--font-main`.

| Токен | Значение | Роль |
| --- | --- | --- |
| `--type-caption` | 10px | Компактные метки. |
| `--type-small` | 12px | Подписи и служебный текст. |
| `--type-secondary` | 14px | Вторичный текст. |
| `--type-body` | 16px | Основной текст. |
| `--type-case-title` | 34px | Заголовки кейсов. |
| `--type-intro` | `clamp(27px, 3vw, 33px)` | Вводный крупный текст. |

Для примеров в style guide роль `.ds-caption` использует 12px; 10px применяется именно к `.ds-tag`.

## Отступы, радиусы и ширина

`--space-1`…`--space-11`: 4, 8, 12, 16, 24, 32, 40, 48, 62, 80 и 120px. Шаги 62px и 120px сохраняют/нормализуют широкие интервалы исходного портфолио.

| Токен | Значение |
| --- | --- |
| `--radius-control` | 9999px |
| `--radius-card` | 24px (18px на мобильном) |
| `--radius-media` | 16px (12px на мобильном) |
| `--page-width` | 1600px |
| `--content-width` | 1040px |

## Движение

Длительности `--motion-duration-instant`, `fast`, `normal`, `medium`, `slow`, `cinematic`: 120, 180, 260, 380, 560 и 760ms. Функции сглаживания: `--motion-ease-standard`, `--motion-ease-out`, `--motion-ease-in-out`.

Используйте motion-токены для взаимодействий, а не задавайте новые произвольные длительности. Уважайте системную настройку уменьшения движения.
