# Паттерны

Все новые стили используют префикс `ds-` и объявлены в [`assets/design-system.css`](../../assets/design-system.css). Примеры доступны на [странице системы](../../design-system/index.html).

## Каркас

| Класс | Назначение |
| --- | --- |
| `.ds-page` | Центрированный контейнер страницы с максимальной шириной 1600px. |
| `.ds-container` | Контентная колонка шириной до 1040px с адаптивными боковыми полями. |
| `.ds-stack` | Вертикальный стек с шагом по умолчанию 32px. |
| `.ds-section` | Вертикальный ритм секции и разделительная линия между соседними секциями. |

## Элементы управления

### Действие

`.ds-action` применяется к ссылкам и кнопкам. По умолчанию это тихая пилюля с фоном поверхности, при наведении появляется лёгкая синяя подложка, фокус клавиатуры обозначается контуром. Кнопку отключайте атрибутом `disabled`. Для ссылки с `aria-disabled="true"` дополнительно блокируйте активацию в коде.

```html
<div class="ds-action-row">
  <a class="ds-action" href="/case/">Открыть кейс</a>
  <button class="ds-action" type="button" disabled>Недоступно</button>
</div>
```

Для ряда действий используйте `.ds-action-row`.

### Метка

`.ds-tag` подходит для периода, категории или короткого статуса. Используйте компактный текст и не полагайтесь только на цвет, чтобы передать смысл.

```html
<span class="ds-tag">2025</span>
```

## Карточки

### Карточка проекта

`.ds-card` оформляет превью кейса или проекта: заголовок, опциональная метка, изображение и короткое описание. Для кликабельной карточки используйте ссылку и модификатор `.ds-card--interactive`.

Рекомендуемая структура: `.ds-card__header` → `.ds-card__identity` с `.ds-card__mark` и `.ds-card__title` → `.ds-card__media` с изображением → `.ds-card__description`.

### Карточка шота

`.ds-shot-card` показывает отдельный экран или визуальную работу. Медиа размещается в `.ds-shot-card__media`, подпись — в `.ds-shot-card__title`. На широком экране подпись раскрывается при наведении или клавиатурном фокусе; на мобильном остаётся видимой.

### Страница кейса

Используйте `.ds-case` как ограничитель ширины. Основные роли: `.ds-case__title`, `.ds-case__lead`, `.ds-case__facts`, `.ds-case__fact`, `.ds-case__label`, `.ds-case__value`, `.ds-case__cover`, `.ds-case__section`.

Секции кейса строятся последовательно: краткое описание, факты о роли и периоде, обложка, затем текстовые разделы с изображениями или материалами проекта.

## Адаптивность и состояния

- На 900px уменьшается часть вертикального ритма и длительность некоторых анимаций.
- На 640px сетка токенов и подписей становится одноколоночной, карточки и радиусы уплотняются.
- На 390px сокращаются поля страницы и минимальная высота карточки шота.
- `.ds-action`, `.ds-card` и `.ds-shot-card` имеют видимый `:focus-visible`.
- При `prefers-reduced-motion: reduce` трансформации отключаются, переходы сводятся к минимуму.
