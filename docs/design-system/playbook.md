# Playbook

Практический порядок сборки нового статического экрана по дизайн-системе.

## 1. Подключите основу

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="/assets/design-system.css">
</head>
```

Для GitHub Pages, развёрнутого в подпути, проверьте базовый путь ресурса. В этом репозитории адрес сайта — корневой, поэтому `/assets/design-system.css` подходит.

## 2. Соберите каркас

Задайте язык документа и используйте семантические `header`, `main`, `section` и `footer`. Ограничьте содержимое классом `.ds-container`; для одноколоночного ритма примените `.ds-stack`.

## 3. Выберите паттерн

Используйте [каталог паттернов](patterns.md): `.ds-action`, `.ds-tag`, `.ds-card`, `.ds-shot-card` и `.ds-case`. Не добавляйте новый вариант, если существующий паттерн можно собрать из тех же семантических элементов.

## 4. Работайте через токены

Цвет, размеры, радиусы и движение берите из [`tokens.md`](tokens.md) и CSS custom properties. Для вторичного текста на новых экранах используйте `--color-text-secondary`; для ссылок — `--color-link`.

## 5. Проверьте доступность и адаптивность

- Задайте содержательное `alt` для значимых изображений; декоративным оставьте `alt=""`.
- Ссылки и кнопки должны быть доступны с клавиатуры и иметь видимый фокус.
- Не маскируйте отключённую ссылку одним только `aria-disabled`; отключите её активацию.
- Сверьте композицию на ширинах около 900px, 640px и 390px.
- Сохраняйте поддержку `prefers-reduced-motion`.
- Для мелкого текста используйте контрастные семантические роли, а не legacy muted.

## 6. Обновите источник истины

Если новый паттерн повторяется и нужен следующим экранам, обновите CSS, этот каталог и Figma-компоненты в одной итерации. Существующие главная страница и кейсы не мигрируются автоматически.
