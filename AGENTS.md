# Правила работы с макетами

## Источник дизайна

- Макет Figma, указанный пользователем, — источник истины для внешнего вида страницы.
- Повторяй макет точно. Не добавляй, не убирай и не переосмысливай элементы без указания пользователя.
- Не заменяй заданные значения похожими значениями из дизайн-системы. Используй токены сайта, только если они совпадают с макетом.

## Перед началом работы

- Найди нужный фрейм и просмотри его целиком.
- Сверь структуру и параметры слоёв: размеры, позиции, выравнивание, отступы, шрифты, начертания, цвета, заливки, обводки, скругления и тени.
- Для элементов, уже используемых на сайте, сначала проверь их вид и состояния на соответствующей странице.
- Проверь, какие текстовые и графические материалы уже есть в проекте.

## Не додумывай

- Не придумывай тексты, переводы, изображения, заглушки, ссылки, действия, состояния или адаптивные правила, которых нет в макете или запросе.
- Если параметр не виден или его нельзя однозначно определить, сначала задай пользователю конкретный вопрос.
- Если макет и запрос расходятся, уточни, чему следовать, до внесения спорного изменения.

## Реализация

- Используй существующую структуру и технологии проекта.
- Не меняй другие страницы и компоненты, если это не требуется для поставленной задачи.
- Сохраняй существующее поведение сайта, если пользователь не попросил его изменить.
- Для страницы без согласованного перехода не добавляй ссылку с главной.

## Сверка результата

- До завершения открой локальную страницу и сравни её с макетом сверху вниз.
- Для точного сравнения используй размер фрейма Figma; отдельно проверь адаптивные размеры, если они заданы в макете или запросе.
- Исправь все заметные расхождения в геометрии, типографике, цветах и состояниях до показа результата.
- В ответе кратко укажи, что сделано, где открыть локальный результат и какие детали остались неясными.

## Git и публикация

- Не создавай коммит и не публикуй изменения без прямой просьбы пользователя.
